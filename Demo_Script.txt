00:00   Data discovery and setup
We are testing how an image reader extracts fields from job applications and medical intake forms. The setup command prints the Python, Pillow, and Codex versions, then downloads the handwritten digit archive from U C I. It scans 3,823 labeled rows, keeps one sample of each digit, and checks the selection against the copy in the repository. The forms use fictional personal information.
Command: python3 automation/demo.py setup --work runs/video-v2

00:25   Generating test cases
The next command runs the team's generator. Each output line corresponds to a row of the decision table. Take test eleven. C one means a normal capture, I five selects print-style writing, and O one requires every field to match. The generator places the sampled digits in the phone field and saves the image, prompt, expected values, and fingerprint. Sixteen cases use fourteen distinct images.
Command: python3 automation/generate.py --out runs/video-v2/images

00:50   Data augmentation
Here is the same medical form before and after augmentation. On the clear image the box next to asthma has a visible outline and no check mark. The first transformation lowers brightness to forty-two percent. The twelve expected values stay the same. The second covers that checkbox with glare and rotates the page ten degrees. Once the entire mark disappears, the answer key changes from false to illegible. The script rebuilds both images and verifies their fingerprints.
Command: python3 automation/demo.py augment --work runs/video-v2

01:18   Executing the automation scripts
This command runs the actual Codex test script against the newly generated images. The runner gives each session the form and its prompt. The local scorer keeps the answer key separate. We run the glare case once, the blank-field case once, and the consistency case three times. The terminal shows each verdict and elapsed time as the requests finish.
Command: python3 automation/run_codex.py --fixtures runs/video-v2/images --case TC04 TC14 TC16 --repeat 1 --jobs 2 --out runs/video-v2/fresh

01:40   Automatic field validation
Look at the two different meanings of missing information. In test fourteen the email and insurance lines are visibly blank. Codex returns null for both, so all twelve checks pass.
